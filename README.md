# Shelter Adopsi Database

Final Project UAS Pemrograman Basis Data — Sistem Manajemen Adopsi Hewan Shelter.

## Isi Repository
- `shelter_adopsi.sql` — dump lengkap basisdata (tabel, function, procedure, trigger, view)
- `seed_adopter.sql` — seeder data dummy untuk tabel `adopter` (3000 baris, generate pakai Python Faker)
- `ERD_shelter_adopsi.png` — Entity Relationship Diagram

## Cara Import
1. Buat database baru bernama `shelter_adopsi`
2. Import `shelter_adopsi.sql` lewat phpMyAdmin
3. (Opsional) Import `seed_adopter.sql` untuk mengisi data adopter
